# Contributing

Thank you for helping improve the CoreX Capital AI public reference repository.

## What we accept

Public contributions should be limited to documentation quality, accessibility, public demo UX, examples, schema clarity, typo fixes, and non-proprietary interoperability improvements.

## What must never be submitted

Do not submit:

- proprietary trading or signal-generation logic;
- model weights, training data, private research, or internal thresholds;
- broker credentials, API keys, tokens, account data, or user data;
- production infrastructure configuration or internal network details;
- licensed third-party charting source or private integration code;
- content copied from a private repository.

## Before opening a pull request

1. Run `python scripts/validate_public_repo.py`.
2. Ensure examples use synthetic data only.
3. Keep changes narrowly scoped and explain the public value.
4. Confirm that no third-party license terms are violated.

By contributing, you confirm that you have the right to submit the material and that its inclusion does not disclose confidential or proprietary information.
